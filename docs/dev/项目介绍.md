# 深知 AI 助手 · 项目介绍

本文说明产品做什么、目前已实现哪些需求与功能。进度按日记更新见 [开发日志](./开发日志.md)，发现与搜索专项见 [发现与搜索页面进度](./发现与搜索页面进度.md)，完整需求见 [PRD](../prd/PRD-AI搜索.md)，代码见 [GitHub](https://github.com/Hakrin-dev/shenzhi)。

## 产品是什么

深知 AI 助手是网站里的智能问答能力。用户从首页进入，可以像搜索引擎一样查文献，也可以切换到问 AI，在对话里选择大模型、选择回答风格、上传文档或开启联网搜索，系统逐字返回答案，并在需要时展示引用来源。

网站用 Next.js 做页面和接口，AI 能力目标形态在 Python FastAPI。用户只访问网站，不直接连 AI 服务。界面采用深知蓝为主色、智能体青绿为点缀，详见 [配色说明](./配色说明.md)。当前 dev 主分支与 feat ai agent B 实验分支并行，下文分别说明各自已落地的功能。

## dev 主分支已实现

**搜索与入口**

首页有统一搜索框，可在普通搜索与问 AI 之间切换。Enter 发送问 AI 并跳转 agents ask，Shift+Enter 换行。普通搜索进入 Knowledge Search 结果页；智能搜索进入 agents ask。

**输入框与工具栏**

界面参考 alphaXiv 第二轮。输入区下方只保留四个控件：加号、上传、模型 pill、圆形箭头发送。加号与上传为无圆框图标，仅模型 pill 保留圆角边框。工具栏去掉中间分割线，输入区高度收窄。

点击模型 pill 展开三行面板：第一行快速与深度模式切换；第二行回复风格（头脑风暴、简明扼要、全面细致、严谨质疑），子菜单向右展开；第三行模型列表，点击后向下展开并盖住上面两行。加号菜单内保留插件、技能与联网开关，子菜单向右展开。上传用于本地文件与知识库引用。配额以紧凑圆环显示剩余次数。

**大模型选择**

模型 pill 点开可向下展开列表，展示各家模型名称与厂商标识，不是回复风格。当前目录见 apps web lib data chat models ts，接口字段 model 传模型 ID。

已配置 DeepSeek V3 与 DeepSeek R1，dev 上可直接选。GPT-4o、GPT-4o mini、Claude 3.5 Sonnet、Gemini 2.0 Flash、GLM-4 Plus 在列表中展示，需订阅后启用。下拉菜单优先向下展开，贴近屏幕底部时会自动向上翻转，避免被浏览器裁切。

后端 GET search config 与创建会话接口已接收 model 字段，FastAPI 仍返回占位文案，尚未按所选模型路由到各家 API。

**问 AI 与对话**

问 AI 页支持多轮输入、流式展示、停止生成。会话与流式协议已搭好，网站转发 FastAPI。问 AI 流式会先检索论文库并通过 refs 事件返回引用列表，生成正文仍为占位。会话未持久化，配额与历史列表未做。

**登录**

支持邮箱注册与登录、GitHub 登录，基于 Better Auth 与 PostgreSQL。

## feat ai agent B 实验分支已实现

B 分支在旧目录结构下把第一阶段核心需求跑通。

**问 AI 与模型**

已接入 DeepSeek 真流式（V3 与 R1），R1 支持思考链折叠面板。支持多轮、停止与继续、四档风格、Markdown 与公式渲染。历史会话已持久化，含会话列表与消息 CRUD API。模型侧仍为 default / subscription / byok 三档，与 dev 多厂商 pill 列表不是同一套 UI，合并时需统一。

**附件与联网**

可上传 PDF、Markdown、文本并解析正文；C 模块已接 Tavily 优先、SearXNG 降级的联网搜索。参考来源卡片为真实数据，正文 [N] 与卡片双向高亮。单附件 3 万、多附件合计 6 万字截断并告警。

**登录与用户**

NextAuth v5 + Prisma + SQLite，含注册、登录、找回密码与路由守卫。会话与消息已写库，历史列表可加载回灌。
