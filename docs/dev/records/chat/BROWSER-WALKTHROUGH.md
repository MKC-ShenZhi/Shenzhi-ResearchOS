# Chat 浏览器走查（手工）

照着做即可。每步只记 **通过 / 不通过**。不通过时抄：做了什么、屏幕上看到什么、Network 里那条红请求的状态码。

## 开始前（做一次）

1. 双击仓库根目录 `start-dev.bat`（或确认 PG、Backend `:8000`、Web `:3000` 都已起来）。
2. `apps/backend/.env` 里必须有 `CHAT_DATABASE_URL`。没有的话侧栏刷新就没了，后面「迁移」也会提示「暂不支持迁移」。
3. 准备 **两个** 能登录的账号：A（主测）、B（隔离）。用 **无痕窗口** 登 B，避免和 A 抢同一浏览器。
4. 走查用 **Chrome**，打开 DevTools → Network，勾选 Preserve log。
5. 浏览器打开：<http://localhost:3000/agents/ask>  
   先 **不要登录**。

模型列表若全是兜底、或提问立刻失败：先看 Backend 窗口和 Postgres 是否在跑，不要继续后面步骤。

---

## 1. 未登录能问、侧栏日期正常

1. 在输入框打一句「走查：匿名第一问」，回车。
2. 等回答结束（不再跳动）。
3. 看左侧历史：刚这句在最上面。
4. 看这条的时间：**年份应是 2026**，不能是 `1970/1/21` 或 `1970/1/22`。
5. 按 F5 刷新。对话和侧栏都应还在。

| 通过 | 不通过 |
| --- | --- |
| 有回答、刷新还在、年份 2026 | 没回答 / 刷新没了 / 年份 1970 |

---

## 2. 登录后先点「暂不迁移」（404 是正常的）

1. **不要关这个标签页**，用页面里的入口登录账号 A。
2. 应弹出 **「迁移对话历史？」**，文案里有「1 条」（或你刚问的条数）和账号 A。
3. 点 **「暂不迁移」**。弹窗关。
4. 看地址栏若还是 `?session=...`，Network 里 `GET .../sessions/...` 可能是 **404**。这是预期：没迁，登录身份读不到匿名会话。
5. 点侧栏「新对话」或打开 `/agents/ask`（不要带旧 session）。不要以为登录坏了。

| 通过 | 不通过 |
| --- | --- |
| 有弹窗；点暂不迁移后能继续用；404 只出现在旧链接 | 没弹窗 / 一点登录就整页挂掉 / 没有确认就自动迁走了 |

---

## 3. 再登录（或刷新问 AI 页）后点「迁移到当前账号」

1. 刷新 <http://localhost:3000/agents/ask>（已登录 A）。
2. 弹窗再出现。点 **「迁移到当前账号」**，按钮会变成「正在迁移…」。
3. 弹窗应自己关上。
4. 左侧应出现刚才那条匿名对话。年份仍是 **2026**。
5. 点开它，再问一句「走查：登录后续问」。应接着同一会话回答。
6. 再 F5：两条都在，账号还是 A。

| 通过 | 不通过 |
| --- | --- |
| 点迁移后侧栏有旧对话，续问成功 | 提示「暂不支持迁移」（多半没开 PG）/ 侧栏没有 / 续问开了新会话 |

---

## 4. 生成到一半再迁移（可抽测）

1. 无痕 **未登录**，提一个会答比较久的问题，**不要等它说完**。
2. 同一窗口立刻登录 A。
3. 弹窗里点 **「迁移到当前账号」**。
4. 允许看到：「部分对话仍在生成，已完成的对话已迁移。请稍后点击重试。」
5. 等那条回答结束，再点 **「重试迁移」**。弹窗应关上，侧栏能点开这条。

| 通过 | 不通过 |
| --- | --- |
| 生成中可先跳过，结束后重试能迁上 | 登录失败 / 生成被打断后会话消失 |

---

## 5. 账号 B 看不见 A 的对话

1. 无痕打开 <http://localhost:3000/agents/ask>，登录账号 B。
2. 左侧 **不应** 出现账号 A 刚迁过去的那几条。
3. 把 A 的对话链接（带 `?session=`）贴到 B 的地址栏回车。页面打不开这条，Network 里该 session 为 **404**。

| 通过 | 不通过 |
| --- | --- |
| B 侧栏没有 A 的历史，贴链接也是 404 | B 能看到或能继续 A 的对话 |

---

## 6. 可选：收藏和删除

在账号 A、已迁过的会话上：

1. 收藏（或重命名）→ 刷新 → 还在。
2. 删除 → 侧栏没了；再打开原链接 → 404。

---

## 不要当成故障的现象

| 现象 | 原因 |
| --- | --- |
| 登录后旧 `?session=` 返回 404 | 还没点「迁移到当前账号」 |
| `/chat/config` 503、模型列表像默认那几个 | Backend 没起来或 BFF 连不上 8000 |
| 提问后会话查库 500 | Postgres 没起来或没配 `CHAT_DATABASE_URL` |
| 控制台一条认领失败，但已经登录成功 | 认领失败不应挡登录；看弹窗提示再点「重试迁移」 |
