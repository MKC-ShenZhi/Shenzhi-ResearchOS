## 后续查明的具体原因

只读查看现有Chrome Admin标签页，确认已载入deepseek-budget-r1三档修订，页面显示「请求参数不合法，请检查字段格式与长度」，风险审批记录为空。对照代码发现由Agent离线准备的DeepSeek预算配置漏了ModelBudgetProfile继承V2必填的schema_version=1；此字段在三档发布包中均缺失，请求会在PublishPlans解析阶段返回422，根本没有进入发布Service。先前仅查询数据库未定位到该包结构缺陷。

修正数据源JSON及本地待发布包，为三个DeepSeek预算补齐schema_version=1；未变更修订号，因为数据库中从未安装该修订。Admin提交前提示缺失的模型风险审批记录。Backend仅对Admin路径的参数校验错误返回具体字段位置，不回显输入值。需重选修正后的同名JSON文件，浏览器已读入的旧对象不会自动随磁盘文件刷新；新错误提示需Backend载入新代码。本次未代发发布请求、修改数据库或运行测试。
