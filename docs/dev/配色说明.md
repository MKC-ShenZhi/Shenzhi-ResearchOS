# 深知配色说明

本轮围绕论文检索、阅读、文献管理和 AI 辅助研究，提供安静、清晰、适合长期阅读的配色。沿用项目现有技术栈、布局、内容、业务功能和主题机制。

## 两套视觉方向与三份 Theme

### 靛色方案

视觉定位：理性、清晰、克制，以靛色操作提示建立科研工具的专业秩序。

靛紫与靛蓝归为同一视觉方向，保留两份实现供比较：

- `indigo-research.css`：日间主色 `#51478A`，夜间主色 `#B5ABE4`。
- `warm-indigo.css`：日间主色 `#4F46E5`，夜间主色 `#A5B4FC`。

品牌色集中用于主要操作、链接和选中态，论文标题与正文保持中性。优势是操作识别稳定、信息层级明确；风险是靛蓝可能与常见生产力工具趋同，靛紫过量会削弱沉静感。

### 青绿方案

视觉定位：暖白与深灰承载科研内容，青绿集中于操作与状态，形成安静的阅读气质。

`warm-teal.css` 的日间页面为 `#FBFAF4`，卡片为白色，主色为 `#1C7783`；夜间主色为 `#7BD4D8`。日间主色根据对比度从设计建议中的 `#20808D` 调深。

青绿是本轮个人首选，尚需组内和导师确认。优势是暖白阅读感与克制的品牌识别能够兼顾；风险是强调色与成功语义较接近，需结合既有图标、文字及使用场景辨认。

## 当前使用与替换方式

`apps/web/styles/globals.css` 当前唯一导入：

```css
@import "./themes/indigo-research.css";
```

比较其他方案时，将该行替换为 `warm-indigo.css` 或 `warm-teal.css`，一次只保留一个候选 Theme 导入。三份配置各提供 44 个日间与 44 个夜间颜色变量，名称一致；完整值见 `apps/web/styles/themes/` 中对应 CSS。

## 夜间层次与品牌一致性

三份 Theme 共用相似的中性深灰层次：页面 `#151515`、侧栏 / 顶栏 `#1B1B1B`、卡片 `#222222`、浮层 / 悬停 `#2A2A2A`、边框 `#393939`。正文为 `#E7E7E7`，标题为 `#F0F0F0`，次要文字为 `#A8A8A8`。

夜间强调色、按钮前景和选中背景分别为：

- 靛紫：`#B5ABE4`、`#211B38`、`#302B41`。
- 靛蓝：`#A5B4FC`、`#171C35`、`#282F48`。
- 青绿：`#7BD4D8`、`#102525`、`#233638`。

各主题的日夜强调色保持同一色系，灰阶用于区分容器。成功、警告、错误保留独立语义。参考 [Radix 中性色与强调色的搭配思路](https://www.radix-ui.com/colors/docs/palette-composition/composing-a-palette)，使用深知自拟色值。

## 语义变量分工

- 页面 / 容器：`background`、`sidebar`、`topbar`、`card`、`popover`、`panel`、`chip`、`line`。
- 文字：`ink` 用于标题，`body` 用于正文，`ink-2` 用于辅助内容，`muted` / `faint` 用于次要信息。
- 主操作：`primary`、`primary-deep`、`primary-soft`、`primary-foreground`。
- 交互状态：`hover`、`active`、`selected`、`selected-foreground`、`selection`、`selection-foreground`。
- 智能体、中性操作、品牌徽章及成功 / 警告 / 错误使用各自语义颜色。
- 遮罩与滚动条：`overlay`、`scrollbar`。

兼容别名为 `surface → card`、`surface-muted → panel`、`border → line`。主色背景与 `primary-foreground` 配对，中性操作与 `neutral-foreground` 配对，金色徽章与 `brand-gold-foreground` 配对。

## 外观模式与阅读

桌面在侧栏「设置」悬停菜单底部选择日间 / 夜间 / 跟随系统；移动顶栏按钮在日间 / 夜间之间切换。默认系统模式、偏好保存、系统响应和首屏行为均沿用现有实现。

PDF 保留原始白纸。论文图片、图表、图谱数据色、模型 Logo 保留其信息含义。

## 检查与比较

仓库根目录运行：

```powershell
node tests/visual/check-color-tokens.mjs
```

颜色检查覆盖三份 Theme 的 336 组不透明文字与背景组合，均达到至少 4.5:1。最低受测对比度：靛紫日间约 4.82、夜间约 5.71；靛蓝约 4.57 / 5.55；青绿约 4.54 / 5.33。

统一比较发现 / 搜索、AI 助手、知识库论文检索三个页面，固定视口、内容和状态，每份 Theme 分别展示日间与夜间。截图使用固定论文快照和明确标记的 AI 展示样例，用于视觉比较，不作为实时推荐或模型生成验收证据。截图保存在项目外验收目录。

对比度检查不能代表全站无障碍认证；透明叠层、全部交互状态、移动端和长期阅读体验仍需实际检查。原有 `/knowledge/topics` 页面缺少 Suspense 边界，完整生产构建的预渲染限制另行处理。
