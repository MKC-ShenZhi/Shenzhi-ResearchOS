## 一、当前进展（实现功能）

**首页与搜索入口**

首页统一输入框支持普通搜索与问 AI。Enter 发送问 AI 并跳转 agents ask，Shift+Enter 换行。普通搜索进入 Knowledge Search 结果页，问 AI 携带问题、模型、风格等参数。

**输入框界面（alphaXiv 第二轮）**

加号与上传为原版无圆框图标。紧挨其右为模型 pill（仅 pill 有圆角边框）。点击 pill 展开三行：模式为快速与深度切换（类似日夜间切换）；风格为头脑风暴、简明扼要、全面细致、严谨质疑，子菜单向右展开；模型行点击后列表向下展开并盖住上面两行。加号菜单内插件与技能亦向右展开，联网开关保留。

**搜索与快捷键**

Enter 发送问 AI，Shift+Enter 换行。普通搜索进入 Knowledge Search 结果页，工具栏去掉中间分割线，输入区高度收窄。

**大模型与配额**

模型列表使用各厂商 logo。配额以紧凑圆环显示剩余次数，替代文字行。

**视觉与交互**

全站配色改为深知蓝体系，见配色说明。下拉菜单默认向下展开，空间不足时自动向上翻转。问 AI 页与首页共用同一 Composer 组件。

**后端与文档**

论文搜索已统一接入 Knowledge Search，问 AI SSE 返回检索 refs；多模型 config 与占位生成仍在。飞书 CLI 一键同步进度页。

## 二、问题 / 情况

**界面与交互**

早期工具栏按钮过多，搜索与问 AI、回复风格、模型选择并列展示，与 alphaXiv 简洁布局不符。用户难以区分「模型列表」与「回复风格」，曾误以为模型选择就是四档风格。

下拉菜单默认向上展开，在首页等位置会被浏览器顶部裁切，列表显示不全。

**功能与数据**

原先模型选项仅为默认、订阅、API 接入三档，无法体现 GPT、Claude、GLM 等各家的选择。普通搜索已统一接入 Knowledge Search，但中文检索能力仍取决于知识底座。dev 上 FastAPI 未按 model 真正调用各家 API，选模型后回答内容不变。GPT 等条目需订阅，当前仅展示不可选。

**分支与合并**

feat ai agent B 已有真流式、附件、联网，与 dev 新界面尚未合并，两套模型 UI 并存。

## 三、改进方案

**布局**

以 alphaXiv 为参照，工具栏只保留加号、上传、模型、发送；搜索模式切换与回复风格移入加号菜单；发送统一为圆形箭头。

**模型**

新增 chat models 目录与 ModelProviderBadge，扩展 ChatModelOption 与后端 config，用具体 model ID 替代 default 等抽象档位；pill 展示当前模型名，下拉列出各厂商条目。

**下拉定位**

新增 use popover placement，优先向下展开，检测视口后自动翻转；容器使用 overflow visible，提高 z-index。

**文档与协同**

按项目介绍、开发日志、配色说明拆分 dev 文档；本页按四段结构单独记录发现与搜索模块进度。

**后续待做**

FastAPI 按 model 路由真实调用；从 B 分支迁入流式与附件联网；Knowledge Search 与 Chat grounding 联调；订阅模型权限与配额联调。

## 四、改进后情况

**界面**

首页与问 AI 页均为四控件工具栏，加号菜单内含模式切换、回复风格、联网等。模型 pill 可展开完整多厂商列表，与风格选择不再混淆。

**下拉**

加号菜单、模型列表、上传菜单均默认向下展开，问 AI 页贴底时自动向上翻转，顶部裁切问题已消除。

**模型与接口**

前端可选 DeepSeek V3 与 R1；GPT、Claude、Gemini、GLM 在列表中可见并标注需订阅。创建会话时 model 字段传 deepseek-chat 等 ID，后端 config 与前端目录一致。普通搜索走 Knowledge Search，智能搜索走 Knowledge2Chat。
