## 1. 背景与目标

发现页(`/`)顶部是产品的核心入口:一个与 AI 助手同款的智能提问框。用户输入自然语言问题后进入**深度搜索结果页**,系统阅读论文库/专利库/学者库等知识源,生成**带来源引用的结构化回答**,并支持多轮追问。

当前原型为纯静态演示:搜索提交后仅跳转路由,结果页展示写死的示例回答(「扩散模型在机器人策略学习中的最新进展」)。本 PRD 定义 AI 搜索的完整产品需求。

### 1.1 目标

- 一个统一提问框承载搜索与对话入口,降低用户学习成本;
- 回答必须**有据可查**:每个关键论断带 [N] 引用标记,可点击跳转到参考来源;
- 支持四种回答模式与三种模型接入方式,覆盖快速查证到深度调研的场景;
- 支持上传 PDF / 引用知识库 / 引用历史对话 / 引用科研项目,把用户私有上下文纳入回答;
- 会话可保存、可回看、可分享、可沉淀到知识库。

### 1.2 非目标(本期不做)

- Deep Research(多步骤自主调研,含研究看板/流程画布)与 Auto Research——属 `/agents/deep-research`、`/agents/auto-research`,另立 PRD;
- 回答中的图表自动生成(本期仅文本 + 表格);
- 多模态提问(图片输入)。

## 2. 角色与使用场景

| 场景 | 描述 |
| --- | --- |
| 快速查证 | 「RDT-1B 的参数量是多少?」→ 快速模式,秒级短回答 + 少量引用 |
| 文献调研 | 「扩散模型在机器人策略学习中最近 6 个月有哪些突破性进展?」→ 深度模式,结构化长文 + 完整参考列表 |
| 灵感探索 | 「这个方向还有哪些没被做过的空白点?」→ 灵感模式,发散式建议 |
| 质疑验证 | 「这篇论文的方法真的比 DP3 好吗?」→ 质疑模式,批判性分析与反证 |
| 私有上下文问答 | 上传自己论文 PDF / 引用自己的科研项目,问「我的方法和 SOTA 差在哪?」 |

## 3. 功能需求

### 3.1 统一提问框(Composer)

出现位置:发现页顶部(搜索入口)、深度搜索结果页底部(吸底追问框)、AI 助手页(空状态居中 + 对话后吸底)。三处为同一组件,仅 placeholder 与弹出菜单方向不同。

#### 3.1.1 输入区

- 多行文本输入,默认 2 行高;
- `Enter` 发送,`Shift+Enter` 换行,**输入法组合中(isComposing)Enter 不发送**;
- 内容为空时发送按钮置灰不可点;
- 输入长度上限 2000 字,超出禁止输入;
- placeholder:
  - 发现页:「帮我找一下关于扩散模型在机器人控制中的最新综述…」
  - 结果页追问框:「继续提问,或上传 PDF / arXiv 链接以扩展上下文…」
  - AI 助手页:「使用'@'引用或使用'/'唤起插件或技能…」

#### 3.1.2 模型选择(框内右上)

下拉三选一,默认「默认」:

| 选项 | 含义 | 权限 |
| --- | --- | --- |
| 默认 | 平台内置模型,所有用户可用 | 全部用户 |
| 订阅 | 订阅用户专属的高性能模型 | 订阅用户;非订阅用户点击引导开通 |
| API接入 | 使用用户在设置页配置的自有 API Key 调用 | 需先在 设置 → API 配置 |

- 选择仅对当前会话生效,新会话回到「默认」。

#### 3.1.3 模式选择(框内右下,发送键左侧)

蓝底触发按钮 + 下拉,四选一,默认「快速」:

| 模式 | 图标 | 产品定义 | 响应形态 |
| --- | --- | --- | --- |
| 快速 | ⚡ | 直接回答,检索 ≤5 篇来源 | 短回答(≤300 字)+ 引用列表,P95 首字 ≤ 3s |
| 深度 | 🔍 | 检索阅读 20+ 篇来源,生成结构化调研报告 | 分节长文 + 对比表格 + 参考来源卡片组 |
| 灵感 | 💡 | 基于检索结果发散,给出可探索方向/假设 | 编号列表,每条含理由与相关来源 |
| 质疑 | ❓ | 对用户问题/指定文献做批判性分析,找反例与局限 | 「论点—质疑—证据」结构 |

#### 3.1.4 「+」菜单(框内左下)

点击展开,三项(本期均为平台插件框架的入口占位):

- **插件**:插件列表与启用管理;
- **技能**:预置技能(如「生成周报」「文献对比表」);
- **联网搜索**:开关项,开启后回答可引用平台知识库以外的公开网页来源,来源卡片标注「网页」。

#### 3.1.5 别针菜单(附件与引用,框内左下)

点击展开五项;后三项悬停向右展开二级面板:

| 项 | 行为 |
| --- | --- |
| 上传本地文件 | 文件选择器,支持 PDF/DOCX/MD/TXT,单文件 ≤20MB,单次 ≤5 个;上传后解析全文纳入上下文,框内以 chip 展示附件名,可单独移除 |
| 上传本地文件夹 | 选择一个文件夹,自动过滤支持的格式,≤50 个文件,其余同上 |
| 引用知识库 | 二级面板按 论文库/专利库/项目基金库/学者关系/研究机构 五组,点击组名向下展开条目列表,支持搜索过滤;选中后以引用 chip 加入提问 |
| 引用历史对话 | 二级面板平铺历史会话列表(按时间倒序),选中后该会话的问答摘要纳入上下文 |
| 引用科研项目 | 二级面板平铺用户科研项目,选中后项目简介 + 里程碑纳入上下文 |

- 附件/引用 chip 位于输入框上方区域,可逐个删除;发送后随消息保存;
- 粘贴 arXiv 链接(形如 `arxiv.org/abs/xxxx.xxxxx`)到输入框,发送时自动识别为引用(拉取该论文全文),框内提示「已识别 1 个 arXiv 引用」。

#### 3.1.6 发送

- 发现页提交:跳转 `/agents/deep-search?q=<urlencoded>`,携带当前模式与模型选择;
- 结果页/助手页提交:在当前会话内追加一轮问答。

### 3.2 深度搜索结果页 `/agents/deep-search`

页面布局:左侧「近期研究」栏(宽 208px)+ 右侧主内容区(最大宽 1180px)。

#### 3.2.1 近期研究栏(ResearchNav)

- 顶部「+ 开启新研究」按钮:创建全新会话并清空当前上下文;
- 下方「近期研究」列表:当前用户的历史会话,按最近活跃倒序,每项显示标题(首问截断)+ 相对时间 + 引用篇数(如「2 小时前 · 18 篇引用」);
- 当前会话高亮;点击其他项切换会话(保留各自完整上下文);
- 未登录用户不展示此栏,会话不保存。

#### 3.2.2 会话顶栏

- 绿色状态点 + 会话标题(取首问)+ 模式标签(如「深度研究 · 自动更新中」);
- 「自动更新中」:深度模式下,系统按该主题监控新文献,有新结果时顶栏出现红点提示「有 3 篇新文献,点击更新回答」;
- 右侧「Pro 模式」按钮(订阅入口,本期点击跳订阅页)与「分享」按钮:
  - 分享:生成只读链接 `/share/<token>`,含完整问答与参考来源,7 天有效,可随时取消分享;被分享者无需登录可查看。

#### 3.2.3 用户提问区

「你的提问」标签 + 问题全文(含附件/引用 chip 回显)。

#### 3.2.4 回答卡片(AnswerCard)

- 头部:深知 AI 圆形图标 + 「深知 AI · 深度研究」+ Pro 徽标(使用订阅模型时显示)+ 元信息「已阅读 N 篇论文 · 耗时 X.Xs」;
- 正文为流式输出(打字机效果),结构由模式决定;深度模式典型结构:概述段落 → 编号小节(如「1. 代表性方法与对比」)→ 对比表格 → 趋势编号列表 → 结论段;
- **引用标记 [N]**:正文中每个来源论断句末带 [N] 上标(主色),与底部参考来源一一对应;点击 [N] 平滑滚动到对应来源卡片并高亮闪烁一次;
- **对比表格**:深色面板内嵌表格,系统推荐项整行主色高亮 + 「· 推荐」后缀;
- 生成中:底部显示「停止生成」按钮;生成失败:显示「回答生成失败,点击重试」,保留已输出内容;
- 回答操作条(生成完成后显示,原型未含,实现时补充):复制 / 重新生成 / 保存到知识库 / 点赞 / 点踩(点踩弹出可选原因表单)。

#### 3.2.5 参考来源卡片组(ReferenceGrid)

- 标题「参考来源 · N 篇」+「查看全部 →」(超过 8 篇时跳转完整列表视图);
- 网格卡片(2–4 列自适应):圆形编号(与正文 [N] 对应)+ 来源标签(会议/期刊/机构,如「CoRL 2024 · Stanford」)+ 标题(3 行截断)+ 作者 · 引用数;
- 系统重点推荐的来源卡片为琥珀色高亮边框与底色,标签含「推荐」;
- 点击卡片:平台内来源跳对应详情页(论文 `/papers/[id]` 等);外部来源新窗口打开;
- 联网搜索来源标注「网页」标签。

#### 3.2.6 继续深入研究(FollowUps)

- 回答生成完成后,系统生成 3–5 个追问建议 chips(圆角胶囊 + 箭头);
- 点击 chip 立即以该问题发起追问(填入并发送);
- 建议须与会话上下文相关,不得重复已问内容。

#### 3.2.7 底部追问框(ChatInput)

吸底 Composer(菜单向上弹出),下方一行辅助说明:「支持上传 PDF / arXiv 链接 · 对话可保存到知识库 · 引用 [N] 可点击跳转」。

追问继承当前模式与模型选择,允许追问中修改。

### 3.3 AI 助手页 `/agents`(轻量对话)

- 与深度搜索共用 Composer 与会话能力,差异:无左侧近期研究栏之外的页面结构、默认不强制引用(快速对话定位);
- 空状态:居中 Logo 图标 +「有什么我可以帮你研究的?」+ Composer + 4 个建议问题 chips(可配置);
- 左侧对话历史栏:「新对话」按钮 + 历史列表,与深度搜索会话**共用同一份会话数据**(助手会话类型为 chat,搜索会话类型为 research,列表各自过滤);
- 建议问题 chips 点击直接发送。

### 3.4 会话保存与知识库沉淀

- 已登录用户的每轮问答实时保存;
- 「保存到知识库」:将某轮回答(含引用)存入论文库的「我的笔记」分区,标题默认取问题前 30 字,可编辑;
- 会话支持重命名与删除(近期研究栏悬停出「···」菜单,原型未含,实现时补充)。

## 4. 内容与安全要求

1. **引用真实性**:回答中 [N] 必须来自实际检索到的来源,禁止编造;检索无结果时明确回答「未找到相关文献」而非强行作答;
2. 每轮回答至少校验:引用编号与来源列表一一对应,编号连续;
3. 涉敏内容(政治敏感、学术不端协助如代写论文)按平台内容安全策略拦截,统一话术;
4. 上传文件仅用于当次回答与用户本人会话,不进入公共语料;用户删除会话时关联文件解析结果一并删除;
5. 联网搜索来源需标注且与平台知识库来源区分展示。

## 5. 非功能需求

- **性能**:快速模式 P95 首字延迟 ≤ 3s;深度模式 P95 首字 ≤ 8s,全文 ≤ 60s;追问继承上下文不得全量重算;
- **并发**:单用户同时进行的生成任务 ≤ 2,超限排队并提示;
- **配额**:未登录每日 3 次(仅快速模式);免费登录用户每日 20 次(深度 ≤ 5 次);订阅用户按方案,超限弹出订阅引导;
- **可用性**:生成中断(网络断开)后回到页面可看到已生成部分,可一键续传;
- **埋点**:各模式使用占比、首字延迟、引用点击率、追问率、追问建议点击率、保存知识库率、分享率。

## 6. 错误与边界

| 场景 | 行为 |
| --- | --- |
| 检索无来源 | 回答「未找到足够相关的文献,建议换个问法或开启联网搜索」,不展示参考来源区 |
| 模型超时 | 已输出内容保留,末尾提示「生成中断,点击继续」,按钮续传 |
| 配额用尽 | 发送前拦截,弹订阅引导;未登录用户引导登录 |
| 附件解析失败 | chip 标红「解析失败」,可移除或重试;不阻塞其余附件 |
| 文件超限 | 选择时即拦截,提示「单文件不超过 20MB,单次最多 5 个」 |
| 问题过长/空 | 空禁止发送;超 2000 字禁止输入并提示 |
| 分享链接过期/取消 | 访问者看到「该分享已失效」页 |

## 7. 验收标准(摘要)

1. 发现页输入问题回车 → 进入结果页,问题回显,回答流式生成,元信息「已阅读 N 篇 · 耗时 Xs」真实;
2. 深度模式回答含小节、表格、编号趋势列表;正文 [N] 点击滚动到对应来源卡片;
3. 四种模式回答结构符合 §3.1.3 定义;三种模型选择权限控制正确;
4. 上传 PDF 与粘贴 arXiv 链接均可作为上下文被回答引用;
5. 引用知识库/历史对话/科研项目可从别针菜单选中并以 chip 加入提问;
6. 追问多轮上下文连贯;追问建议 chips 可点击发送;
7. 近期研究栏可切换/新建会话,刷新后会话仍在(登录用户);分享链接可被未登录者只读访问;
8. 配额、并发、超时、无来源等边界行为符合 §6。
