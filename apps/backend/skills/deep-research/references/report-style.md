# Report style

结论先行：任何交付物的第一段必须能独立回答问题。选能装下当前深度的最小形状——快速回答是直接回答加 caveat，深度综述是含结论、证据主干、局限冲突、覆盖缺口的完整报告。

分节只在有助导航时用；节的划分跟随问题自身的结构，不套固定模板。代表性论文首次出现给一行条目（作者 et al., 年份, venue + 引用编号 + 一句话贡献）；方法与基准对比用 markdown 表，列头由问题决定，单元格内容可溯源。长文本用换行或引用块。

已确立、迁移推断、未解缺口三者分离呈现；冲突带证据级与权重，不投票不取均值。数字不比来源更精确；来源只说"显著"就不写百分比。报告可以长，普通回答必须简洁。不暴露内部推理。
