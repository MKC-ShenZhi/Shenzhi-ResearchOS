# 报告模板集（composition 按需加载的产物骨架）

模板是**产物结构，不是过程**：它们只约束交付物的形状，不改变检索、阅读深度、停止规则——那些由 orchestrator 决定。骨架可按问题裁剪（节允许空缺并声明原因，不允许为填节编内容），但所有模板都保留四件必备：结论、证据挂靠、局限冲突、覆盖说明。

| 模板 | 用户会问的问题 | 特征 |
|---|---|---|
| survey 综述 | "X 这个方向研究到什么程度了？" | 按概念组织、综合节、缺口分析 |
| paper 精读 | "这篇论文讲的什么？方法细节？" | 单篇/少篇深读、机制与实验细节 |
| comparison 对比 | "A 和 B 该走哪条路线？" | 逐轴裁决、分歧归因、选用条件 |
| screening 筛选 | "按这些条件筛出符合的论文" | 纳入/排除计数、可数理由、特征表 |
| proposal 开题 | "这个选题的 gap 成立吗？" | 空白论证、三自检、切入定位 |
| related-work 相关工作 | "帮我起草论文的相关工作" | CARS 三步、方法族、并发标注 |

auto（默认）= 模型按问题自选最合适的形状（快速回答/标准交付/深度综述三档右尺寸逻辑仍在）。

---

## survey 领域综述

```markdown
# {题目：具体到问题本身}

## 结论
一段话回答"该领域研究到什么程度"：最重要的判断与限定条件，每个承重主张带 [n]。

## 背景与概念界定
关键术语的学术定义与演变；定义有分歧时并列呈现，不择便。

## {主题一}（按概念组织，不按作者或年代）
先给该主题的结论句，再给证据与机制；一致在哪、分歧为何（方法？数据？理论框架？）；
主题内可按时间梳理演进（奠基→修正→当前前沿），每个日期带引用。

## {主题二…}（2–6 个主题，相邻主题间加过渡句）

## 综合
主题之间如何关联：主流观点是什么、领域实际在往哪走。这一节是综述的价值——论证，不是复述。

## 已知局限与冲突
（四件必备之一，含反方最强论证——高深度时对主要争议结论启用）

## 覆盖地图（扫描变体，问题问"版图/都有人做什么"时用）
子方向 × 方法矩阵，格子填代表性论文与数量；**空格就是空白区**，不填内容不解释，让空白自己说话。

## 缺口与推荐阅读
缺口按六类识别（证据/知识/实践/方法/经验/理论空白），每条说明为什么是真空白；
3–5 篇入手文献，各配一句"为什么从它读起"。

## 覆盖说明（四件必备之一，含渠道×轮次与读深分布）
```

## paper 论文精读

```markdown
# {论文标题}（作者 et al., 年份, venue）

## 一句话
它做了什么、解决了什么问题、最重要的结果。

## 背景与动机
这个问题为什么存在、之前的方法卡在哪。

## 方法
核心机制逐步展开（配公式/结构说明，页码引用）；与之前工作的关键差异在哪。

## 实验
设置（数据集/基线/指标）→ 主结果（数字逐字来自原文，带页码）→ 消融与分析。

## 局限与批评
论文自述的 limitations；他人（或你检索到的）批评与失败复现。

## 值得追的后续
这篇论文打开了什么、后续工作沿哪些方向展开（带引用）。

## 覆盖说明
```

## comparison 方法对比

```markdown
# {X} 与 {Y}：{问题} 对比

## 结论（裁决）
一句话裁决 + 置信度（现有证据够不够撑起这个裁决）+ **什么条件下裁决会翻转**。

## 对比对象界定
X、Y 各一段：定义、适用范围、提出者；明确"本文不比较什么"，防止范围漂移。

## 对比轴：{轴 1}
对比表（列头由该轴的问题决定）；轴末一句结论："该轴上 X/Y 在 {条件} 下胜出，但 {caveat}"。

## 对比轴 {轴 2…}（3–6 轴）

## 一致之处
X 与 Y 没有实质差异的方面——防止报告为了"对比感"编造冲突。

## 分歧及其成因
每个实质分歧三层归因：经验观察（谁测到了什么）→ 方法原因（数据/基线/设置不同）→ 理论原因（框架不同）。

## 选用建议
什么条件选 X、什么条件选 Y、什么条件暂不选（等新证据/缺口未补）。

## 证据局限
对比所依赖的证据有什么局限（仅摘要级？样本少？设置不同代无法直接比？）。

## 覆盖说明
```

## screening 筛选清单（PRISMA-lite，非预注册）

> 本模板须在方法节诚实标注：agent 单一执行、非预注册、知识库渠道边界——**不冒充正式 PRISMA 系统综述**。

```markdown
# {条件} 筛选结果

## 结论
一段话：筛出几篇、主要特征分布、最重要的观察。

## 筛选条件
纳入标准逐条；排除标准逐条（可界定的，不是"不相关"）。

## 方法
检索策略表（渠道 × 查询 × 命中 × 纳入）；筛选流程记数（识别 → 去重 → 筛选 → 全文评估 → 纳入，
每级数量，**排除理由要可数**——"不相关"不算理由）；流程局限如实标注。

## 纳入研究特征表
每行一篇：研究/年份/任务或样本/方法/设置/结果/证据强度。数字逐字来自原文。

## 观察
按结果主题组织的叙述性综合；冲突发现并列呈现并归因。

## 覆盖说明
```

## proposal 选题背景

> 论证性文体（为选题铺路），但事实主张仍逐条带 [n]；不得为立论夸大证据或静默隐瞒冲突证据——说服力来自 gap 的精确，不来自剪裁。

```markdown
# {选题} 研究背景与立论

## 问题陈述
这个题目为什么重要：谁受影响、规模、不解决的代价。每个经验性主张带 [n]。

## 已有认识
2–3 段综合已确立的知识：基础机制 → 已确立发现 → 已收敛的共识。只用最强证据。

## 已有尝试及其不足
既有路线逐条：在什么场景有效、在什么情况下失效（引论文原述，不贬低——这些作者大概率是评审）。

## 空白（立论核心）
精确陈述 gap，三条标准逐条自检：**具体**（不是"还需更多研究"）、**可攻克**、**重要**。
标注空白类型（六类 gap 之一）及识别信号。

## 本研究的切入点
一段话：为什么该走的下一步是自然延伸。止步于定位，不展开方法。

## 覆盖说明
```

## related-work 相关工作素材

> 给作者的使用说明写在最前：哪些段落可直接改写、哪些位置需要作者填自己的判断。**贡献声明（Move 3）留给作者，你不代笔。**

```markdown
# {论文题目} 引言与相关工作素材

## 研究背景（Introduction 素材）
CARS 三步：领域重要性（Move 1）→ 已有路线及其不足（Move 2）→ 本研究定位（Move 3 占位符，作者填）。

## 相关工作：{类别 1 前辈方法}
每族方法一段，引 3–5 篇，指出该族的局限。

## 相关工作：{类别 2 相邻问题}
这些工作与本研究问题的区别在哪。

## 相关工作：{类别 3 最接近的工作}
1–2 段精确对比，提供"与 X 的区别在于…"句式素材；
**只与实验上真正对过基线的工作做性能表述，其余一律框为并发/正交工作**——近期工作不冒充被超越的基线。

## 时间线与并发工作
奠基 → 演进脉络一段；明确列出哪些近期工作属于 concurrent。

## 引用清单
本素材引用的全部论文条目（作者 et al., 年份, venue + [n] + 一句话），供作者逐条核对。

## 证据局限与覆盖说明
本素材的证据局限（摘要级/全文级比例、缺一手验证的断言点名）+ 常规覆盖说明。
```
