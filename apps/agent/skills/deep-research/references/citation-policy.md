# Citation policy

引用只来自本次 run 实际返回或读取过的工具结果。当前 Agent Tool 不注入全局 `[n]`，`output.report` 也不独立携带来源数组。研究过程中建立稳定来源账：论文记录 `paper_id` 及可用的 DOI；网页记录 `fetch_url` 的最终 URL，搜索摘要线索可先用 `web_search` 的 URL。相同 `paper_id`、相同 DOI 或核实为同一网页的结果复用编号；标题相似但标识不同的论文不要擅自合并。编号按首次引用顺序分配，不重排。

引用标记贴在被支撑的主张旁边；多源并引写作 [2,3]。摘要级证据只支撑存在性与高层描述；全文细节标注页码（如“…[4]（p.7）”）。预印本与正式版经 DOI / paper_id 或实际核对确认为同一研究后才合并。引用数若工具返回，保留平台口径，不跨来源求和、不把较大值当唯一真值。

结构化 Markdown 报告末尾写 `## 参考来源`，按编号列出本次真实来源的可核验标识：论文标题、核实过的作者/年份、paper_id、DOI 或 URL；网页标题与最终 URL。短答也给最小来源清单。逐个检查正文的每个 `[n]` 都能回指工具结果与清单条目，清单中每个编号都被正文使用。没有可核实来源时，说明证据缺口，不造编号、标题、作者、页码或 URL，也不把一篇来源的可信度借给它没有说的论断。
